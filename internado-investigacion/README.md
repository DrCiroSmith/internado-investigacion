# internado-investigacion

![Flujograma](https://raw.githubusercontent.com/DrCiroSmith/internado-investigacion/main/img/flujo-simplificado.png)

Ecosistema portátil y seguro para análisis clínico con Jupyter, Python 3.12, MySQL 8.0 y Docker.

---

## 🔄 Flujo simplificado del proyecto

1. **Clona el repositorio**
2. **Configura `.env`**
3. **Coloca tus archivos Excel en `data/`**
4. **Levanta el entorno con Docker**
5. **Accede a Jupyter y explora tus datos**
6. **Carga datos limpios a MySQL**
7. **Sincroniza notebooks y scripts con GitHub**
